# CodeMentor: AI Наставник по коду

## Описание
Чат-бот принимающий на вход описание задачи по программированию и код от студента. Ментор находит ошибки в решении студента, но не выдаёт готовый код, а ведёт к решению ступенчатыми подсказками. Запоминает типичные ошибки студента и предлагает похожие задачи.

## Текущая стадия проекта

На данном этапе проект находится на обсуждении. Идет подготовка к разработке: составление дизайн-документов, распределение ролей, определение стэка.

Дизайн-документ проекта можно найти -> */docs/ml_system_design_cod.md*

## Ожидаемый результат MVP
Чат с уровнями подсказок, историей ошибок. Прототип, позволяющий провести воспроизводимую оценку качества автоматического выявления ошибок и генерации образовательных подсказок.
